# Publicación de prueba

Crear un repositorio PRIVADO en GitHub llamado edersa-explorador-prueba y subir el contenido de esta carpeta, incluida data/. No subir el ZIP como único archivo.

En Streamlit Community Cloud, Create app → desplegar desde el repositorio → rama main → app.py → Python 3.12. No requiere Secrets para esta copia de prueba. Configurar la aplicación como pública para compartir su enlace.

Datos: corte del 17/11/2026. Se excluyen nombres, domicilios, observaciones libres, coordenadas GPS y el campo de electrodependencia de la copia de respaldo. Se conservan NIS, ID de usuario, consumos y características mostradas en el tablero. Los originales y las planillas de Drive no se modificaron. La copia no se actualiza automáticamente.
